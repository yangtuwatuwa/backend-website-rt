# 📄 Bab 11: Administrasi Surat Menyurat & Template Surat RT

Bab ini berisi panduan lengkap penggunaan endpoint backend untuk **Surat Masuk**, **Surat Keluar**, dan **Manajemen & Unduh Template Surat RT**.

---

## 📩 1. Sistem Surat Masuk (Incoming Letters)

Digunakan oleh **RT** dan **Sekretaris** untuk mencatat surat yang diterima dari pihak luar (misalnya dari Kelurahan, Kecamatan, atau Instansi lain).

### A. Catat Surat Masuk Baru
* **Method & Route:** `POST /admin/surat-masuk`
* **Headers:** `Authorization: Bearer <token_jwt_rt_atau_sekretaris>`
* **Rules & Validasi:**
  * `instansi_pengirim`: Wajib diisi, maksimal 200 karakter. (Contoh: `"Kelurahan Sawangan Baru"`).
  * `perihal`: Wajib diisi, maksimal 200 karakter. (Contoh: `"Rapat Posyandu Kelurahan"`).
  * `no_agenda`: Dihasilkan otomatis oleh backend dengan format `SM/YYYY/XXX` (Contoh: `SM/2026/001`).
  * `tanggal_masuk`: Otomatis diisi dengan timestamp waktu saat ini (`NOW()`).
* **Request Body (JSON):**
  ```json
  {
    "instansi_pengirim": "Kelurahan Sawangan Baru",
    "perihal": "Rapat Posyandu Kelurahan"
  }
  ```
* **Response Sukses (201 Created):**
  ```json
  {
    "response": 201,
    "output": {
      "pesan": {
        "id": 1,
        "no_agenda": "SM/2026/001"
      },
      "token": null
    },
    "message": "Registrasi surat masuk berhasil dicatat masbro"
  }
  ```

### B. Ambil Daftar Surat Masuk
* **Method & Route:** `GET /admin/surat-masuk`
* **Headers:** `Authorization: Bearer <token_jwt_rt_atau_sekretaris>`
* **Response Sukses (200 OK):**
  ```json
  {
    "response": 200,
    "output": {
      "pesan": [
        {
          "id": 1,
          "no_agenda": "SM/2026/001",
          "tanggal_masuk": "2026-07-20T09:38:00.000Z",
          "instansi_pengirim": "Kelurahan Sawangan Baru",
          "perihal": "Rapat Posyandu Kelurahan",
          "created_at": "2026-07-20T09:38:00.000Z"
        }
      ],
      "token": null
    },
    "message": "Daftar surat masuk berhasil diambil masbro"
  }
  ```

## 📑 3. Fitur Template Surat RT (Upload, Download & Management)

Digunakan untuk menyediakan berkas format surat (seperti Template Surat Pengantar KTP/KK, Keterangan Domisili, Pengantar Nikah, Izin Keramaian) yang dapat diunduh oleh warga maupun pengurus RT.

### Ketentuan File Upload:
* **Folder Penyimpanan Backend:** `./uploads/templates/`
* **Format File yang Diizinkan:** `.pdf`, `.doc`, `.docx`, `.xls`, `.xlsx`
* **Batas Maksimal Ukuran File:** `10 MB`

---

### A. Upload Template Surat Baru (Sekretaris / RT Only)
* **Method & Route:** `POST /admin/template-surat`
* **Headers:** `Authorization: Bearer <token_jwt_rt_atau_sekretaris>`, `Content-Type: multipart/form-data`
* **Form-Data Params:**
  * `file`: (File fisik berkas template)
  * `judul`: `Template Surat Pengantar KTP / KK` (Wajib, max 200 karakter)
  * `deskripsi`: `Format standar RT 05 untuk pengurusan KTP/KK di Kelurahan`
  * `kategori`: `KTP/KK`
* **Response Sukses (201 Created):**
  ```json
  {
    "response": 201,
    "output": {
      "pesan": {
        "id": 1,
        "file_name": "template-1721468200-123456789.docx"
      },
      "token": null
    },
    "message": "Upload template surat berhasil masbro!"
  }
  ```

---

### B. Ambil Daftar Template Surat (Warga & Admin)
Mendapatkan daftar template surat yang siap diunduh.
* **Method & Route:**
  * Warga: `GET /resident/template-surat`
  * Sekretaris / RT: `GET /admin/template-surat`
* **Query Params (Opsional):** `?search=KTP`
* **Headers:** `Authorization: Bearer <token_jwt>`
* **Response Sukses (200 OK):**
  ```json
  {
    "response": 200,
    "output": {
      "pesan": [
        {
          "id": 1,
          "judul": "Template Surat Pengantar KTP / KK",
          "deskripsi": "Format standar RT 05 untuk pengurusan KTP/KK di Kelurahan",
          "kategori": "KTP/KK",
          "file_path": "template-1721468200-123456789.docx",
          "original_name": "Template_Surat_Pengantar_KTP.docx",
          "created_at": "2026-07-20T09:56:00.000Z",
          "updated_at": "2026-07-20T09:56:00.000Z"
        }
      ],
      "token": null
    },
    "message": "Daftar template surat berhasil diambil masbro"
  }
  ```

---

### C. Mengunduh Format Template Surat (Warga & Admin)
Mengunduh file fisik template surat untuk diisi oleh warga/sekretaris.
* **Method & Route:**
  * Warga: `GET /resident/template-surat/download/:id_template`
  * Sekretaris / RT: `GET /admin/template-surat/download/:id_template`
* **Headers:** `Authorization: Bearer <token_jwt>`
* **Response:** Mengirimkan *stream* file fisik dari server (Browser/Client akan otomatis mengunduh file).

---

### D. Update / Timpa Template Surat (Sekretaris / RT Only)
* **Method & Route:** `PATCH /admin/template-surat/:id_template`
* **Headers:** `Authorization: Bearer <token_jwt_rt_atau_sekretaris>`, `Content-Type: multipart/form-data`
* **Form-Data Params (Kirim yang ingin diubah saja - Opsional):**
  * `file`: (File fisik baru jika ingin mengganti berkas lama)
  * `judul`: `Template Surat Keterangan Domisili Warga`
  * `deskripsi`: `Format baru 2026`
  * `kategori`: `Domisili`
* **Response Sukses (200 OK):**
  ```json
  {
    "response": 200,
    "output": {
      "pesan": {
        "fieldCount": 0,
        "affectedRows": 1,
        "changedRows": 1
      },
      "token": null
    },
    "message": "Template surat berhasil diperbarui masbro!"
  }
  ```

---

### E. Hapus Template Surat (Sekretaris / RT Only)
Menghapus record dari database sekaligus menghapus file fisiknya dari folder server.
* **Method & Route:** `DELETE /admin/template-surat/:id_template`
* **Headers:** `Authorization: Bearer <token_jwt_rt_atau_sekretaris>`
* **Response Sukses (200 OK):**
  ```json
  {
    "response": 200,
    "output": {
      "pesan": {
        "affectedRows": 1
      },
      "token": null
    },
    "message": "Template surat berhasil dihapus masbro!"
  }
  ```

## 📡 Live Sync WebSocket Events

Ketika terjadi aktivitas pada fitur ini, backend secara otomatis memancarkan event Socket.io berikut:

| Event `type` | Pemicu Broadcast di Backend | UI Frontend yang Harus Refetch |
|---|---|---|
| `"surat_masuk"` | Registrasi Surat Masuk baru ditambahkan. | Tabel Surat Masuk Sekretaris/RT. |
| `"surat_keluar"` | Pencatatan Surat Keluar baru ditambahkan. | Tabel Surat Keluar Sekretaris/RT. |
| `"template_surat"` | Template surat baru di-upload, di-update, atau dihapus. | Grid Card Template Surat Warga & Sekretaris. |
